# Sistema de Gestión de Matrices Objetuales en Java

## Descripción

Este proyecto consiste en el desarrollo de una aplicación en **Java** que implementa el uso de **matrices objetuales**, donde cada posición de la matriz almacena un objeto en lugar de un dato primitivo.

El propósito del proyecto es fortalecer los conocimientos en **Programación Orientada a Objetos (POO)** mediante la aplicación de conceptos como:

- Clases y objetos.
- Encapsulamiento.
- Constructores.
- Métodos.
- Arreglos bidimensionales de objetos.
- Manipulación y recorrido de matrices.

La aplicación permite registrar, consultar, modificar y visualizar la información almacenada en la matriz, proporcionando una solución organizada y eficiente para la gestión de datos.

## Objetivos

- Comprender el funcionamiento de las matrices objetuales en Java.
- Aplicar los principios de la Programación Orientada a Objetos.
- Desarrollar habilidades en el manejo de arreglos bidimensionales.
- Implementar operaciones básicas sobre estructuras de datos compuestas por objetos.
- Crear una aplicación modular, legible y fácil de mantener.

## Tecnologías utilizadas

- **Java**
- Programación Orientada a Objetos (POO)
- IDE recomendado: IntelliJ IDEA, Eclipse o NetBeans
